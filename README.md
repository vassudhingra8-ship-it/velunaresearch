# Research Website Starter

This is a simple academic website template for GitHub Pages.

## Files
- `index.html` — main page content
- `style.css` — website styling

## How to publish on GitHub Pages
1. Create a GitHub account.
2. Click **New repository**.
3. Name the repository something simple, for example: `research-website`.
4. Upload `index.html` and `style.css`.
5. Go to **Settings** > **Pages**.
6. Under **Build and deployment**, choose:
   - **Source**: Deploy from a branch
   - **Branch**: `main`
   - **Folder**: `/ (root)`
7. Save.
8. Wait a minute or two.
9. Your site link should appear in the Pages section.

Typical GitHub Pages URL:
`https://yourusername.github.io/research-website/`

## How to edit the content
Open `index.html` and replace the placeholder text with your own research writing.
